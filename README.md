# Pawsitive Vibezz — new site

A free static website starter with a Magical + Modern design. It works without WordPress or Blogger.

## Publish free
The easiest option is GitHub Pages or Cloudflare Pages. Upload the five files in this folder and publish the project as a static site. No paid hosting is required.
